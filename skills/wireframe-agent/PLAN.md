# Tạo Wireframe

## Mục đích

Chuyển Scenario mới thành hệ thống screen, state và transition mobile-first đủ chi tiết để review và tạo Prototype.

## Dùng skill này khi

- Scenario mới đã được chấp nhận.
- Cần thiết kế user flow, navigation, screen và state cho web mobile-first.
- Cần chuẩn bị deliverable Wireframe hoặc đầu vào cho Prototype.

## Input bắt buộc

- `deliverables/02-interaction-design/scenario-new.md` đã chấp nhận.
- Design input có nguồn rõ ràng trong `data/design-inputs/`.
- `templates/wireframe-template.md`, proposal, rubric và rules.

## Output

`deliverables/02-interaction-design/wireframe/` gồm screen/state inventory, user flow, annotation, phiên bản và export kiểm chứng được.

## Workflow

1. Lập screen/state inventory cho bốn đoạn hành trình.
2. Xây user flow, navigation và điểm quay lại/phục hồi.
3. Thiết kế từng screen theo viewport điện thoại với hierarchy, component và nội dung phù hợp.
4. Bổ sung default, loading, empty, error, success, focus và status feedback.
5. Kiểm tra consistency, affordance, accessibility và responsive intent.
6. Ghi công cụ, phiên bản, đường dẫn export và gap còn lại.
